## Local adaptations

Project names, audiences, owning-doc links, sibling repositories and validation commands are local.
Dekopon’s pre-1.0 ban on compatibility/history prose does not apply: this repository retains required
compatibility, recovery, ADR and benchmark context. Product pages distinguish shipped behavior from
current source. Review receipts belong in PRs; dated evidence retains its methodology. Verified prose
corrections are in scope; implementation or contract changes require an owner decision. The upstream
AGENTS score floor and no-backsliding rule are explicit in the local skill. No runtime or release
policy is imported from Dekopon.
